Projects

  • FLN Assessment Platform

    AI-powered Foundational Literacy & Numeracy assessment platform: worksheet generation, competency mapping, and personalized remediation. Role-scoped student management across a 7-role governance hierarchy with privacy-preserving handling of personal identifiers, plus Python pipelines scraping curriculum-aligned problem sets from state and NCERT textbooks.

    VLED Labs, IIT Ropar · 2026

  • Krishi Darshan Transcript Pipeline

    Automated pipeline transcribing Hindi audio from 74 episodes of Doordarshan’s Krishi Darshan. Ran on Kaggle T4 GPUs with a checkpoint/resume system, producing a structured CSV of episode metadata and full transcripts (~3,700 words per episode) for downstream agricultural NLP.

    ANNAM.AI · yt-dlp, Whisper-medium

  • SLM Tool-Calling Benchmark

    Benchmarked six small language models (Qwen2.5-1.5B, Phi-3.5-mini, LFM2.5-1.2B, DeepSeek-R1-Distill-Qwen-1.5B, Phi-4-mini, Ministral-3-3B) on tool-calling accuracy and restraint across 12 prompts. Qwen2.5-1.5B and Phi-3.5-mini tied at 85.7% accuracy, with Qwen ~4.6× faster; verbose chain-of-thought surfaced as a latency/accuracy tradeoff in DeepSeek-R1.

    ANNAM.AI · side project

  • ResearchMatch v2

    Helps students find research internship advisors at premier Indian institutes (IITs, IIITs, NITs, IISc). Every professor is cross-checked through a secondary web search before being surfaced, and cold-email drafts cite real publications from the verified profile.

    Personal project · Live on GitHub Pages

  • Vi-Notes Basic Writing Editor

    Contributed the Basic Writing Editor feature to Vi-Notes, an open-source human authorship verification platform: a controlled React textarea backed by an Express.js / MongoDB Atlas API to persist writing sessions.

    Vicharanashala Lab, IIT Ropar · 2026

  • Multispectral Wound Diagnostics

    Proposed a contactless wound monitoring framework using multispectral imaging (RGB + NIR) with an edge-AI pipeline for temperature, oxygenation, and colorimetric analysis.

    Innovación 2026 · Poster

  • Automatic Plant Watering System

    An automated irrigation system built on Arduino and a soil-moisture sensor, spanning circuit setup, sensor calibration, and testing.

    Arduino project
